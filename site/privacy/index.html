Your data stays on your machine

Effective 28 August 2026

Package and CLI

The package reads files you select on your machine. It does not send file contents, schema, keys, or diagnostics to us. It has no telemetry.

Sample demo

The sample demo compares shipped or selected files in browser memory. It does not upload selected files. Demo state uses the demo: session-storage namespace and is removed when you start for real.

Site delivery

The host may process request metadata to deliver and secure this site. We do not use advertising cookies, fingerprinting, or third-party analytics.

Contact

For privacy questions, use the project’s issue tracker ↗. Do not include private data.
